SETUP NOTES
1. Extract the ZIP and open a terminal inside the jobtrack-pro folder.
2. Create and activate a Python virtual environment.
3. Install dependencies: pip install -r requirements.txt
4. Copy .env.example to .env and set a unique SECRET_KEY for local development.
5. Run: python app.py
6. For Render, configure the environment variables and persistent PostgreSQL database.
7. Optional: register an account before running import_sample_data.py; configure SAMPLE_USER_EMAIL.

IMPORTANT
- The archive contains the source/configuration files listed above.
- Third-party email delivery, password reset emails, OAuth, and external AI APIs are not included/configured.
- Always test database migrations and all routes on a staging deployment before using real data.
